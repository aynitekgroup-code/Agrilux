## ¿Qué es Agrilux?

Plataforma de **agricultura inteligente** que sirve tanto a **pequeños agricultores** (freemium) como a **empresas agroindustriales** (enterprise). Combina IA + datos climáticos + satélite + suelo + conocimiento local.

## Nuestra Solución

### Para el Agricultor (Freemium)

| Función | Fuente |
|---------|--------|
| 📸 Diagnóstico IA (foto → plaga → producto) | Gemini + DeepSeek + GitHub |
| 🎤 Voz español peruano | Speech Recognition + TTS |
| 📅 Ciclo cultivo + alertas preventivas | Conocimiento local |
| 🔍 Búsqueda tiendas + redes sociales | Google Places + DB local |
| 🛰 Satélite (NDVI, clorofila, biomasa) | Sentinel-2 (10m) |
| 🌧 Clima real | Open-Meteo + 70 estaciones SENAMHI |
| 🌱 Suelo (pH, textura, salinidad) | SoilGrids250m |
| 📊 Predictivo (antes de que aparezca) | Clima + etapa + historial |
