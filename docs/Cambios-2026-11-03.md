# Cambios - 3 de noviembre de 2026

**Proyecto:** Agrilux (`com.agrilux.app2`)
**Área principal:** Gestión, navegación y experiencia visual
**Estado:** ✅ Implementado y validado

## Resumen

Se reorganizó el módulo de Gestión para enfocarlo en la configuración de infraestructura agrícola y logística. También se retiraron accesos a módulos que no forman parte del flujo actual y se mejoró la legibilidad de la interfaz manteniendo el contenedor móvil estándar de Agrilux.

## Cambios realizados

### 1. Nuevo flujo de Gestión

**Archivo:** `src/modules/gestion/GestionPage.jsx`

- Se reemplazó el panel anterior por una pantalla guiada de configuración.
- Se añadieron tarjetas para:
  - Telemetría Agrícola.
  - Telemetría de Flota.
- Se incorporaron descripciones, etiquetas, estados y acciones de conexión.
- Se añadió un asistente de configuración de tres pasos:
  1. Vincular fundo o agroexportadora.
  2. Emparejar dispositivos telemáticos.
  3. Validar señal y asignar el dispositivo.
- Se añadieron opciones para trabajo sin conexión y exploración del modo demo.
- Se incluyó una sección de módulos pendientes de activación.
- Se añadieron mensajes visuales de confirmación para las acciones del usuario.
- Se aumentaron tamaños de texto, espacios, botones y áreas táctiles para mejorar la lectura y la usabilidad.

**Motivo:** ofrecer una experiencia moderna, clara e intuitiva para conectar infraestructura real sin mostrar datos ficticios.

### 2. Simplificación de navegación

**Archivos:** `src/App.jsx`, `src/components/Layout.jsx`

- Se retiró el acceso de Mercado de la navegación inferior.
- Se desactivaron las rutas antiguas de Mercado, Ofertas y Voz, redirigiéndolas al diagnóstico.
- `/gestion/finanzas` redirige ahora a `/gestion`.
- Se eliminaron del encabezado y del menú los accesos relacionados con Mercado y Mi tienda.
- Se conservó el contenedor móvil estándar de **430 px**, igual que en las vistas anteriores.

**Motivo:** evitar rutas incompletas o módulos fuera del flujo actual y mantener una navegación coherente.

### 3. Limpieza de accesos internos

**Archivo:** `src/modules/gestion/components/AccesosGestion.jsx`

- Se eliminó el acceso a Salud financiera.
- Se retiró el import del icono que ya no se utiliza.

**Motivo:** mantener únicamente accesos disponibles y alineados con el nuevo flujo operativo.
