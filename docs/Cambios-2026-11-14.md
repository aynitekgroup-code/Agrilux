## Orden de instalación en Supabase (SQL Editor, cada archivo completo)

1. `scripts/agrotrack-reportes-flota.sql` (Actividad con el nuevo criterio)
2. `scripts/agrotrack-geocercas-reportes.sql` (motor de visitas + desglose)
3. `scripts/agrotrack-visitas-diarias.sql` (visitas guardadas + pg_cron)
4. `scripts/agrotrack-tiempo-real.sql` (estado en vivo + Realtime + latido)

Después, una sola vez, para llenar el respaldo de los días ya cargados:

```sql
select public.agrotrack_visitas_dia_calcular_interno('<empresa_id>', d::date, null)
from generate_series(date '2026-11-01', current_date, interval '1 day') d;
```

Si pg_cron no está activo: Database → Extensions → `pg_cron` → volver a ejecutar el paso 3.
