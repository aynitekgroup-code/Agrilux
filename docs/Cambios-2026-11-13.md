## 6. Nota sobre el origen de datos de Reportes

Con la versión demo de `main`, `ReportesPage` usa `src/mocks/agrotrackData.js` y **no consulta Supabase**.

Para trabajar con datos reales se requiere:

1. Ejecutar los SQL en Supabase, en orden: `agrotrack-geocercas.sql`, `agrotrack-posiciones.sql`, `agrotrack-posiciones-resumen.sql`, `agrotrack-reportes-flota.sql`, `agrotrack-geocercas-reportes.sql`.
2. Tener un usuario miembro de una empresa (empresa activa).
3. Importar el reporte Zonar (ZIP o `.xlsx`) desde **Gestión → Mapas → "Cargar reporte de unidades"** (`PosicionesImport.jsx`), que hace `upsert` en `public.agrotrack_posiciones`.
4. Importar geocercas (ZIP shapefile) si se desean reportes de entradas/salidas por zona.

> La versión de `ReportesPage` de la rama (basada en RPCs `agrotrack_*` de Supabase) queda disponible en el historial de Git por si se decide reactivar el modo de datos reales.
