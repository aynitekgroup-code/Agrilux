## LAS 5 RAZONES POR LAS QUE AGRILUX ES DIFERENTE

### 1. 🌐 OFFLINE-FIRST (PWA)
- **Competidores:** Requieren internet constante
- **Agrilux:** Funciona sin señal. El campesino en la chacra sin internet puede diagnosticar
- **Tecnología:** Progressive Web App + IndexedDB + Service Worker

### 2. 🗣️ VOZ EN ESPAÑOL PERUANO
- **Competidores:** Solo inglés o español genérico
- **Agrilux:** Entiende "la hoja está rara" en es-PE, responde como agrónomo campesino
- **Tecnología:** Web Speech API + LLM con prompt agrícola peruano

### 3. 🇵🇪 HIPER-LOCAL PARA PERÚ
- **Competidores:** Genéricos para EE.UU./Europa
- **Agrilux:** Conoce caña de azúcar H57-5174, papa Yungay, SENAMHI, estaciones locales
- **Base de datos:** 55 estaciones meteorológicas peruanas + 7 ciclos de cultivo locales

### 4. 💰 GRATIS (FREEMIUM REAL)
- **Competidores:** $10-500/mes desde el día 1
- **Agrilux:** Gratis para siempre para pequeños agricultores. Solo cobramos a empresas
- **Modelo:** Field (gratis) → Field Plus ($10) → Pro ($50) → Enterprise ($200+)

### 5. 🔄 TODO-EN-UNO
- **Competidores:** Cada uno hace UNA cosa (solo diagnóstico, solo monitoreo, solo clima)
- **Agrilux:** Diagnóstico + clima + suelo + NDVI + voz + mapeo + recomendaciones + SENAMHI
- **Integración:** Todo conectado, un solo lugar
