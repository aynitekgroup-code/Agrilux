El relé corta la bomba de combustible solo cuando la unidad va a menos de 5 km/h. Si está en marcha, la orden queda pendiente hasta que se detenga. Toda orden queda registrada.

3. Secuencia: alerta de robo y corte de motor

sequenceDiagram
  autonumber
  actor S as Supervisor
  participant W as Frontend web / app
  participant SV as Servidor (API + reglas)
  participant BD as Base de datos
  participant R as Red 4G / GPRS
  participant G as Equipo GPS
  participant RL as Relé de corte
  G->>R: Posición + combustible (cada 60 s)
  R->>SV: Trama TCP
  SV->>BD: Guardar posición
  SV->>SV: Evaluar reglas (caída de combustible)
  SV-->>W: Alerta "posible robo"
  S->>W: Pulsa "Bloquear motor" + clave
  W->>SV: POST /ordenes-corte
  SV->>BD: Registrar orden (usuario, motivo)
  SV->>R: Comando de corte
  R->>G: Comando
  alt velocidad < 5 km/h
    G->>RL: Activar salida digital
    RL-->>G: Bomba de combustible cortada
    G->>R: Confirmación
    R->>SV: ACK
    SV->>BD: Orden = Confirmada
    SV-->>W: Motor bloqueado
  else en movimiento
    G->>G: Espera a que se detenga
    G->>R: Pendiente
    R->>SV: Estado pendiente
    SV-->>W: Bloqueo programado
  end

4. Estados de la orden de corte

stateDiagram-v2
  [*] --> Enviada : supervisor o regla crea la orden
  Enviada --> Confirmada : velocidad menor a 5 km/h
  Enviada --> Pendiente : unidad en movimiento
  Pendiente --> Confirmada : la unidad se detiene
  Pendiente --> Cancelada : supervisor cancela
  Confirmada --> Desbloqueada : orden de desbloqueo con clave
  Desbloqueada --> [*]
  Cancelada --> [*]
